Frequently Asked Questions

Are my images uploaded to a server? ＋
No. This tool processes images entirely with the browser's Canvas API. Files are never sent to any external server.
Should I choose JPG, PNG, or WEBP? ＋
Photos with lots of colors compress best as JPG or WEBP. Use PNG if you need a transparent background, such as for logos or icons. WEBP usually produces the smallest overall file size.
Can I reduce file size without losing quality? ＋
Keeping the quality slider above 90% usually results in almost no visible difference while still reducing file size. PNG is lossless, so you'll need to reduce the resolution to shrink a PNG file.
